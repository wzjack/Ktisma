KTISMA CAPITAL GROUP - LOGO FILES
=================================

FULL LOGO (mark + KTISMA / CAPITAL GROUP wordmark)
  ktisma-logo-export.html   Open in Chrome, Edge, Safari or Firefox (internet needed once, to load the
                            font). Pick layout, colors, background and size, then click Download PNG.
                            Sizes: 2,000 / 4,000 / 6,000 px on the longest side.

MARK ONLY (the K)
  png/  4,000 px tall, transparent background, 300 dpi
        ktisma-mark-primary-4000px.png    navy + gold, for light backgrounds
        ktisma-mark-reversed-4000px.png   ivory + gold, for dark backgrounds
        ktisma-mark-black-4000px.png      one color, for black-and-white printing
        ktisma-mark-white-4000px.png      one color, for photos and dark backgrounds
        ktisma-profile-1024px.png         square profile picture (LinkedIn, social media)
  svg/  Vector versions of the same four marks. Scale to any size with no loss of quality.

COLORS
  Navy          #0F1E36
  Gold          #B8975A   (on light backgrounds)
  Light gold    #C9A66B   (on dark backgrounds)
  Gold, text    #8A6A35   (small text on light backgrounds)
  Ivory         #F4F0E8

FONTS (free from fonts.google.com)
  Cormorant Garamond SemiBold   logo wordmark and headlines
  Hanken Grotesk                body text

NOTE
  At very small sizes (under about 24 px) the thinnest top courses of the K blur together.
  The mark still reads as a K; the website favicon uses a simplified set of courses for this reason.
